# Security reporting

Do not publish credentials, player records or exploit details in a public issue.
When this repository is hosted, use GitHub private vulnerability reporting if the
maintainer has enabled it. If unavailable, open a minimal issue requesting a private
reporting channel without disclosing the vulnerability itself.

Only the current alpha branch is intended to receive fixes. This is not a security
audit or a production-readiness guarantee. SQLite and Core economic operations have
known crash-atomicity limitations documented in docs/TESTING.md.
